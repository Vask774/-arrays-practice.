## Выполненные задания

1. **Task1.Statistics** — статистика случайного массива:
   - сумма элементов;
   - произведение элементов;
   - количество чётных чисел;
   - количество чисел больше среднего значения.

2. **Task2.InputSort** — ввод, реверс и сортировка массива:
   - ввод количества элементов;
   - заполнение массива;
   - вывод в прямом и обратном порядке;
   - сортировка по возрастанию;
   - поиск максимального и минимального элементов;
   - обработка ошибок ввода.

3. **Task3.Unique** — поиск уникальных элементов без LINQ и HashSet.

4. **Task4.Exceptions** — обработка исключений при вводе элементов и обращении к массиву.

5. **Final.Task** — индивидуальное задание.

## Индивидуальное задание

**Вариант 1 — Температура за неделю.**

Использован массив температур:

22.5, 23.1, 19.8, 21.3, 24.0, 25.2, 20.7

Программа определяет:

- среднюю температуру;
- максимальную температуру;
- минимальную температуру;
- количество дней с температурой выше 20 °C.

Для вычислений используются LINQ-методы `Average`, `Max`, `Min` и `Count`.
